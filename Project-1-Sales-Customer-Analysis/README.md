# Project 1 - Analisis Transaksi Penjualan dan Pelanggan

Mini project menggunakan SQL dan Excel untuk menganalisis transaksi pelanggan, kontribusi per kota, dan performa transaksi.

Tools:
- SQL
- Excel

Insight:
- Jakarta memiliki kontribusi transaksi terbesar
- Sebagian besar pendapatan berasal dari pelanggan utama
- Jumlah transaksi tidak selalu berbanding lurus dengan nilai transaksi
